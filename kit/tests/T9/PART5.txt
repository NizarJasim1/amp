I4. Repeated rock-paper-scissors (0 = rock, 1 = paper, 2 = scissors; (m + 1) % 3 beats m). Write a class `Player` with
`move(history)` -> 0, 1 or 2, where `history` is the list of (your_move, opponent_move) pairs so far. You play 600 rounds
against each bot in a hidden pool of different kinds of bots (some fixed patterns, some that react to you, some that try to
exploit predictable players, some that change behaviour). Score = average of (wins - losses) / rounds over the pool (HIGHER is better).
